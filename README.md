## Project Description

WikiHow2Network is a beginner-friendly website that introduces basic computer networking topics. It provides short lessons and simple explanations to help learners understand how devices communicate.

## Main Features

- Eight networking lessons covering topics such as IP addresses, DNS, the OSI model, routers, switches, firewalls, ports, and subnetting.
- Search and category filters for finding lessons.
- Lesson progress tracking saved in the browser.
- A searchable networking glossary.
- A short networking quiz with answer feedback.
- A Network Lab that demonstrates a simulated DNS lookup. The demo runs in the browser and does not contact an external service.
- Responsive layout for smaller screens.

## Technologies Used

- HTML for the page structure and forms
- CSS for styling and responsive layout
- JavaScript for lesson content, search and filters, quiz feedback, progress tracking, and interactive demonstrations
- Browser `localStorage` for saving completed lessons

## How to Run

Open `index.html` in a web browser. No package installation or server is required.
